## 📌 Project Overview

The Multi-Property Hospitality Reservation & Management System is a microservices-based backend application developed for the Starlight Stays & Resorts use case.
The system is designed to manage multiple hotel properties, rooms, users, room availability, reservations, and cancellations through independent microservices.
The project demonstrates the use of **Spring Boot, REST APIs, Eureka Service Discovery, OpenFeign, and microservices architecture.

🎯 Problem Statement

Managing multiple hotel properties requires efficient room availability, booking, and cancellation management.
The system aims to provide a secure and scalable platform for seamless hospitality reservation management.

## 💡 Proposed Solution

We developed a microservices-based hospitality reservation system where different business functionalities are divided into independent services.

The system provides:

- Room management
- Real-time room availability checking
- Hotel reservations
- Booking cancellation
- User management
- Service discovery
- Inter-service communication
- REST APIs
- Scalable backend architecture
